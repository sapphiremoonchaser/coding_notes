# R<sup>2</sup>

The proportion of variance in the dependent variable explained by the model.

Ranges from 0 to 1

Limitations:
* R<sup>2</sup> does NOT imply causation
* Higher R<sup>2</sup> does not guarentee a correct model
* R<sup>2</sup> only applie to OLS regression


# Adjusted R<sup>2</sup>

Adjusted R<sup>2</sup> adjusts for the number of predictors in the model.
Unnecessary variables are penalized. 

If R<sup>2</sup> increases:
* The new variable improves the model meaningfully

If R<sup>2</sup> decreases:
* The variable adds noise
